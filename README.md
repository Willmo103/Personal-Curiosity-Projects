# Personal Curiosity Project

## Project Description
This repository is a personal knowledge hub and portfolio where I document my explorations into a wide range of technical subjects. As a developer passionate about continuous learning, I use this space to research new technologies, dissect complex systems, and share my findings. It's a living portfolio designed to showcase my skills and dedication to my craft.

**My research spans many areas, including *but not limited to*:**
 - Software Development: Exploring new languages, design patterns, and efficient coding practices.
 - System Automation: Automating tasks across different operating systems with various scripting languages.
 - Cybersecurity & Forensics: Deep-diving into security concepts and techniques.
 - 3D Modeling & Design: Learning about software and scripting for design.
 - Emerging Technologies: Researching and experimenting with new and evolving tech like Generative AI, Machine Learning, and more.

## Getting Started
This repository is a personal project. However, feel free to explore the content, open an issue for a discussion on a topic, or even submit a pull request if you have valuable insights to share.

## Structure
Each topic is typically organized into its own folder, which may contain research notes, code examples, and links to my published articles or blog posts.
